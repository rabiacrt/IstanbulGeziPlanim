# Istanbul Gezi Planim 🌍

Istanbul Gezi Planim is a web application designed to help users discover must-see places in Istanbul. It provides an interactive guide that allows users to gather information, create personalized routes, and organize travel lists with ease.

## Key Features ✨

- **Map-based Visualization 🗺️**  
  Explore important landmarks and attractions in Istanbul displayed on an interactive map.

- **Create Your Own Map 🛠️**  
  After logging in, users can create and customize their own personal maps.

- **Route Planning 🛣️**  
  Logged-in users can plan their own travel routes tailored to their preferences.

- **Travel Lists 📋**  
  Organize and manage places to visit by creating personalized travel lists after login.

- **Access Sample Routes 🚶‍♂️**  
  Discover recommended travel routes curated for exploring Istanbul.

- **User Reviews & Sharing 💬**  
  Share your travel experiences and insights on the blog page.

## Technologies Used 🛠️

- **MapLibre** — For rendering and visualizing map data.  
- **MapTiler** — Provides map layers and backgrounds.  
- **Firebase** — Handles user authentication and database management.  
- **OpenWeatherMap** — Supplies real-time weather information.

---

This application enables users to efficiently plan their trips without wasting time, enhancing their travel experience through informative map pop-ups and intuitive route planning.
